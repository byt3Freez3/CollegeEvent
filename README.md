# IEM Student Events — Beginner Web Development Assignment

This is a beginner-friendly example for the college event page assignment. It uses plain HTML, CSS and JavaScript (no framework).

## Folder structure

```text
IEM_Event_Page_Beginner/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── images/
│   ├── logo.png
│   └── six event photos
├── REPORT.md
└── README.md
```

## Run it on your computer

1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html`.
4. Right-click the file and choose **Open with Live Server** if you have the Live Server extension. If you do not have it, double-click `index.html` to open it in a browser.
5. Try the event filter buttons, the dark mode button, and the registration form.

## Before submitting

- Replace `[Your Name]` in the footer.
- Replace the sample coordinator and contact details with correct details, or remove details you cannot verify.
- Check with your teacher whether the roll number should be 10 digits.
- Event dates and event descriptions are sample content. Update them if required.
- The forms only demonstrate front-end validation. They do not save data to a database or send email.
- Take your own screenshots after running the site.

## Upload to GitHub

1. Sign in at https://github.com.
2. Click the **+** button near the top-right and choose **New repository**.
3. Name it `iem-student-events` (or the name your teacher asks for).
4. Choose **Public** if your assignment needs a public link. Add a README if you want; this project already has one.
5. Create the repository.
6. On the repository page, choose **Add file → Upload files**.
7. Open the extracted project folder on your computer. Upload `index.html`, `REPORT.md`, `README.md`, and the `css`, `js`, and `images` folders with their contents. Keep the folder names exactly the same.
8. Click **Commit changes**.
9. Open `index.html` in the repository and check that all files are present.

### Optional: publish it with GitHub Pages

1. Open your repository and click **Settings**.
2. Click **Pages** in the left menu.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch `main` and folder `/ (root)`, then click **Save**.
5. Wait a little, then refresh the Pages screen. Open the website link it gives you.
