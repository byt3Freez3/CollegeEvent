## 1. Objective
The objective of this project is to create a simple college event webpage using HTML, CSS and JavaScript. The website shows upcoming events, provides a sample registration form, displays a gallery, and includes department and contact information.

## 2. Technologies used
- **HTML:** Used to create the page structure, navigation, event cards, forms and gallery.
- **CSS:** Used for colours, spacing, cards, image sizing, hover effects and responsive layout.
- **JavaScript:** Used for event filtering, form validation and dark mode.

## 3. Main sections
1. Home — short introduction and navigation.
2. Events — five sample events with date, venue and description.
3. Registration — student details and event selection.
4. Gallery — six images with captions and hover effect.
5. About Us — project description and coordinator placeholders.
6. Contact & Feedback — sample contact details and feedback form.

## 4. JavaScript features
- Event filters show events by category.
- Registration form checks the name, roll number, email, phone and selections.
- Dark mode changes the page appearance.
- Feedback form checks that the user has entered the required information.

## 5. Responsive design
CSS Grid, Flexbox and media queries are used to adjust the event cards, gallery and forms for tablet and mobile screen sizes.

The event information and contact details are sample content. The forms only show front-end validation; they do not save registrations or send messages to a server.
